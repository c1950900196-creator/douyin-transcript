# 抖音文案提取与球赛预测系统

一个面向内容运营与足球分析场景的全栈工具，支持：

- 抖音视频文案提取（ASR）
- 作者监控与自动转写
- 文案库管理与检索
- 球赛预测分析与准确率统计
- 手动匹配比赛与结果纠偏

线上访问地址不在仓库公开文档中展示，请在内部渠道按需分发。

## 核心功能

### 1. 抖音文案提取

- 输入抖音链接自动提取语音并转文字
- 支持视频信息保存（标题、作者、链接）
- 文案保存到本地数据文件，便于二次分析

### 2. 作者监控

- 支持维护作者列表
- 定时检查新视频并自动转写
- 支持作者头像、基础信息同步

### 3. 球赛预测

- 聚合比赛数据并生成预测记录
- 统计博主、豆包、用户预测准确率
- 支持准确率排名和预测历史查看

### 4. 最近版本新增能力

- 统一“视频发布时间”展示（文案库 / 预测记录 / 准确率历史）
- 支持文案库手动标注比赛与预测方向
- 支持预测记录和准确率历史中“修改匹配”
- 准确率页支持“过滤10天未更新”博主

## 技术栈

- 后端：Node.js（原生 HTTP）
- 前端：原生 HTML / CSS / JavaScript
- 语音识别：豆包 ASR / 本地能力
- 进程管理：PM2

## 项目结构（关键文件）

- `server-cloud.js`：云端服务入口（API 路由）
- `match-predictor.js`：比赛与预测核心逻辑
- `author-monitor.js`：作者监控与文案存储
- `predictions.html`：球赛预测与准确率页面
- `transcripts.html`：文案库页面
- `match-dialog.js`：手动匹配弹窗共享逻辑

## 本地启动

```bash
npm install
npm start
```

或：

```bash
node server.js
```

默认访问：`http://localhost:3456`

## 云端部署（腾讯云）

1. 上传代码到服务器目录（示例：`/www/ball-predict-deploy`）
2. 安装依赖：`npm install --production`
3. PM2 启动/重启：

```bash
pm2 restart ball-predict
```
