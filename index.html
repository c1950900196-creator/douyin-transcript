💡 使用说明
  • 需要安装 FFmpeg（Mac: brew install ffmpeg）
  • 需要安装 Python 3（首次使用自动安装whisper）
  • 首次运行会下载模型文件（约500MB），请耐心等待
  • 在抖音App点击「分享」→「复制链接」
  • 粘贴链接后点击「语音转文字」
  • 处理时间取决于视频长度和电脑性能
